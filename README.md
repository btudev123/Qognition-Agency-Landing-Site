# Qognition Agency Website

Next.js App Router site for Qognition Agency with static SEO pages, audit funnels, agent discovery files, and lead capture.

## Local Development

```bash
npm install
npm run dev
```
## Build

```bash
npm run build
```

## Resend and HubSpot

The instant audit funnel uses HubSpot for lead capture and Resend for report delivery.

Setup instructions are in [docs/integrations.md](docs/integrations.md).
